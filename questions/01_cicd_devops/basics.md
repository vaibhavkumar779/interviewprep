# CI/CD & DevOps Fundamentals - BASICS
## Questions Only - Test Yourself

### Core Concepts
1. What is CI/CD? Explain each component separately.
2. What is the difference between Continuous Delivery and Continuous Deployment?
3. What is DevOps? Is it a role, a culture, or a set of tools?
4. What are the key principles of DevOps?
5. What is the DevOps lifecycle? Name all phases.
6. What is Infrastructure as Code? Why does it matter?
7. What is Configuration Management? How is it different from provisioning?
8. What is the difference between imperative and declarative approaches in DevOps?
9. What is a build artifact? Give 5 examples.
10. What does "shift left" mean in DevOps?

### Pipeline Concepts
11. What is a build pipeline? What stages does it typically have?
12. What is a release pipeline? How is it different from a build pipeline?
13. What is a pipeline trigger? Name 4 types.
14. What is the purpose of an artifact repository? Name 3 tools.
15. What is the difference between a job, a stage, and a step in a pipeline?
16. What is a pipeline agent/runner? Why not run everything on the controller?
17. What are pipeline variables vs secrets? How should each be handled?
18. What is a pipeline template? Why would you use one?
19. What is the difference between a self-hosted and cloud-hosted agent?
20. What happens if a step in a pipeline fails? How do you handle it?

### Interview-Style
21. Walk me through a CI/CD pipeline you built from scratch. What stages did it have?
22. What was the most complex pipeline problem you solved? How did you approach it?
23. How do you decide between using a single pipeline vs multiple pipelines for a project?
24. What metrics do you track to measure CI/CD effectiveness?
25. How do you handle database schema changes in a CI/CD pipeline?
